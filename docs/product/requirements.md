# Requirements (MVP)

## Core
- Time-bucketed greeting (static + optional AI fallback)
- Daily check-in: OK | SHARE | SELF_CARE + optional note (max 500)
- History calendar + recent list; edit/delete day
- Stats: week / month / year mood distribution
- Settings: reminder, language (en/vi/th/zh), theme, AI toggle, export, delete all, premium
- Onboarding + splash
- Offline-first; data in local storage only

## Non-goals
- Social graph, cloud account, clinical diagnosis
