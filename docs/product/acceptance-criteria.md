# Acceptance criteria

1. Fresh install defaults to **English**.
2. Home hero image changes by local hour (morning / noon / afternoon / evening).
3. Check-in saves and appears in History same day.
4. Stats bars render without RenderFlex overflow.
5. Language switch updates UI copy via S.* immediately after restart/locale change.
6. Reminder respects notification permission.
7. Delete all data clears check-ins and settings defaults.
8. App icons are circular logo (transparent outside) on Android launcher / iOS icons.
