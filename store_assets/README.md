# Still Here — Store icon assets

- `still_here_google_play_icon_512.png`: Google Play listing icon, 512×512 PNG.
- `still_here_app_icon_1024.png`: 1024×1024 master icon for App Store Connect and design handoff.

The artwork is newly AI-generated for this project and contains no third-party brand marks, copyrighted characters, or stock-photo assets. The icon is also installed into the Android, iOS, and macOS asset catalogs in this source tree.
